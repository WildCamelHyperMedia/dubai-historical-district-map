# Dubai Historical District — Interactive Map

Prototype by Wild Camel HyperMedia FZ-LLC for Dubai Culture.

Open the site root for the web map; add `?mode=kiosk` for the kiosk experience, `?lang=ar` for Arabic, `?orientation=portrait` for a portrait kiosk.

Map artwork and place copy: *The Historical District Map 2026*, Department of Economy and Tourism — used for this prototype only. Opening hours, contacts and Arabic copy are placeholders pending confirmation.
